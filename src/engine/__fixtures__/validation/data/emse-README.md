# Stol, Schaarschmidt & Goldblit (2022) replication matrices

Files `emse-*-s.csv` (sample covariance matrices, N = 155) and `emse-*-nacov.csv`
(asymptotic covariance matrices of the sample covariances, for MLM) are taken
unchanged from the replication package of:

Stol, K.-J., Schaarschmidt, M., & Goldblit, S. (2022). Gamification in software
engineering: the mediating role of developer engagement and job satisfaction.
*Empirical Software Engineering*, 27, 35. https://doi.org/10.1007/s10664-021-10062-w

Replication package: https://doi.org/10.5281/zenodo.6322761 (record 6322761),
licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
